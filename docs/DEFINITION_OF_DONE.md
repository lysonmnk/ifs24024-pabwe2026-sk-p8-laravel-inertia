# Definition of Done (fitur selesai jika semua tercentang)
- [ ] Ada di PRD dan backlog dengan acceptance criteria
- [ ] Design brief dan kontrak selesai
- [ ] Backend sesuai kontrak, Frontend sesuai brief
- [ ] Pint lulus, tidak ada dd()/dump()/console.log
- [ ] Semua tes lulus, tiap response kontrak punya tes
- [ ] Code Reviewer: DISETUJUI
- [ ] Security: LULUS, composer audit bersih
- [ ] QT: SIAP RILIS, edge cases diuji
- [ ] DevOps: deploy sukses, rollback siap
- [ ] Commit sesuai Conventional Commits, keputusan penting dicatat
